Zero Keylogging & Sensitive Input Shield

Zero Keylogging ebong Password o Incognito Surokkha

Every character you type across English QWERTY, Avro Phonetic (অভ্র ফোনেটিক), Probhat (প্রভাত), Direct Bangla Alphabetical (বাংলা বর্ণানুক্রমিক), National / Jatiya (জাতীয়), the Calculator Numpad, 2-Page Currency & Special Symbols, Text Repeater, and Fancy Unicode Fonts is processed strictly inside your phone's volatile memory (RAM) to deliver text to your active app via Android's standard InputConnection API.

আপনি ইংরেজি (QWERTY), অভ্র ফোনেটিক, প্রভাত, সরাসরি বাংলা বর্ণানুক্রমিক, জাতীয় (Jatiya), ক্যালকুলেটর নামপ্যাড, টাকার প্রতীক ও স্পেশাল সিম্বল প্যানেল, টেক্সট রিপিটার কিংবা ফ্যান্সি ফন্টস—যে মোডেই লিখুন না কেন, প্রতিটি অক্ষর শুধুমাত্র আপনার ফোনের র‍্যামে (RAM) তাৎক্ষণিক প্রক্রিয়া হয়ে সরাসরি আপনার ব্যবহৃত অ্যাপে পৌঁছায়।

Apni English QWERTY, Avro Phonetic, Probhat, Bangla Bornonukromik, National (Jatiya), Calculator Numpad, Symbol Panel, Text Repeater ba Fancy Fonts—je mode-ei likhun na keno, protiti okkhor shudhumatro apnar phone-er RAM-e process hoye shorashori active app-e jay.

  • Automatic Password, PIN & Financial Field Freeze: Whenever Android signals a password, visible password, web password, numeric PIN, one-time verification code (OTP), credit/debit card input, URI/URL bar, or email address field, Mukto Keyboard immediately disables word learning, next-word prediction logging, and auto-space interference. পাসওয়ার্ড, পিন ও ব্যাংকিং বক্সে স্বয়ংক্রিয় লার্নিং বন্ধ: যখনই আপনি কোনো পাসওয়ার্ড, পিন, ওটিপি (OTP), ব্যাংক কার্ড নম্বর, ওয়েবসাইট লিংক (URL) বা ইমেইল ফিল্ডে টাইপ করেন, মুক্ত কিবোর্ড স্বয়ংক্রিয়ভাবে শব্দ শেখা (Word Learning) ও প্রেডিকশন সেভ করা সম্পূর্ণ বন্ধ করে দেয়। Password, PIN o Banking Field-e Auto Freeze: Jokhoni apni password, PIN, OTP, card number, website URL ba email field-e type koren, Mukto Keyboard sathe sathe word learning o prediction save kora bondho kore dey.
  • Browser Incognito / Private Mode Respect: Mukto Keyboard honors Android's IME_FLAG_NO_PERSONALIZED_LEARNING flag requested by Chrome Incognito, Firefox Private Browsing, Brave, DuckDuckGo, and secure messengers—zero words or bigrams are written to local storage during private sessions. ইনকগনিটো ও প্রাইভেট ব্রাউজিং সম্মাননা: ক্রোম ইনকগনিটো বা যেকোনো ব্রাউজারের প্রাইভেট ট্যাবে (IME_FLAG_NO_PERSONALIZED_LEARNING) টাইপ করার সময় কিবোর্ড ফোনের লোকাল ডিকশনারিতেও কোনো শব্দ সংরক্ষণ করে না। Incognito o Private Mode Sommanona: Chrome Incognito ba browser-er Private Tab-e (IME_FLAG_NO_PERSONALIZED_LEARNING) type korar somoy keyboard phone-er local dictionary-teo kono shobdo save kore na.

Crash Reporting & Stability Diagnostics

ক্র্যাশ রিপোর্টিং ও অ্যাপ স্থিতিশীলতা ডায়াগনস্টিকস

Crash Reporting o Stability Diagnostics

Sanitized technical stack traces via Google Firebase Crashlytics — zero typed content
গুগল ফায়ারবেস ক্র্যাশলিটিক্সের মাধ্যমে শুধুমাত্র কারিগরি ত্রুটি শনাক্তকরণ — কোনো ব্যক্তিগত লেখা নয়
Firebase Crashlytics-er madhyome shudhumatro technical crash log — kono personal text noy

To keep the keyboard fast and crash-free across thousands of Android models, Mukto Keyboard uses Google Firebase Crashlytics strictly for technical crash diagnostics. Our internal error sanitizer (AppErrorReporter) filters out routine offline/network timeouts and records only code stack traces, Android OS level, device model, and memory state when an unexpected crash occurs. Typed words, clipboard items, Secret Chat messages, AI API keys, and personal identity are never attached to crash reports. Diagnostic crash logs are automatically purged by Firebase within 90 days.

হাজারো ভিন্ন মডেলের অ্যান্ড্রয়েড ফোনে কিবোর্ডটিকে ক্র্যাশ-মুক্ত ও দ্রুত রাখতে শুধুমাত্র কারিগরি ত্রুটি বোঝার জন্য Google Firebase Crashlytics ব্যবহৃত হয়। অ্যাপের নিজস্ব স্যানিটাইজার সাধারণ অফলাইন এরর বাদ দেয় এবং অপ্রত্যাশিত ক্র্যাশ ঘটলে কেবল কোডের ত্রুটির লাইন (Stack Trace), ফোনের মডেল ও অ্যান্ড্রয়েড ভার্সন পাঠায়। আপনার টাইপ করা কোনো শব্দ, ক্লিপবোর্ড, গোপন চ্যাট বা এপিআই কী কখনোই ক্র্যাশ রিপোর্টে যুক্ত হয় না। এসব ডায়াগনস্টিক লগ ৯০ দিনের মধ্যে স্বয়ংক্রিয়ভাবে মুছে যায়।

Keyboard-tike crash-free rakhte shudhumatro technical error bojhar jonno Google Firebase Crashlytics babohar hoy. Crash ghotle kebol code stack trace, phone model o Android OS version jay—apnar type kora kono shobdo, clipboard, Secret Chat ba API key kokhonoi crash report-e jay na. Crash log 90 diner modhye auto-delete hoy.
