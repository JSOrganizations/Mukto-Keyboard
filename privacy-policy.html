Introduction (Bhumika)
About Mukto Keyboard and our privacy commitment
মুক্ত কিবোর্ড এবং আমাদের গোপনীয়তা প্রতিশ্রুতি
Mukto Keyboard ebong amader privacy commitment

Mukto Keyboard (Package ID: com.mukto.keyboard) is developed by Md Mobassher Ahmed Sowrov and published by JS Organization. The application is an Android Input Method Editor (IME) built for fast, intuitive Bengali and English typing.

মুক্ত কিবোর্ড (প্যাকেজ আইডি: com.mukto.keyboard) অ্যাপটি Md Mobassher Ahmed Sowrov দ্বারা তৈরি এবং JS Organization কর্তৃক পরিচালিত। এটি একটি আধুনিক অ্যান্ড্রয়েড ইনপুট মেথড (IME) কিবোর্ড অ্যাপ, যা ব্যবহারকারীদের স্বাচ্ছন্দ্যে বাংলা ও ইংরেজিতে টাইপ করার সুবিধা দেয়।

Mukto Keyboard (Package ID: com.mukto.keyboard) develop korechen Md Mobassher Ahmed Sowrov ebong manage kore JS Organization. Eta ekta modern Android keyboard jeta diye fast Bengali & English type kora jay.

We believe user privacy is an absolute priority. We have engineered Mukto Keyboard under an Offline-First, Privacy-Centric Architecture with an uncompromising zero-keylogging policy. We do not track, collect, record, or transmit your personal keystrokes or sensitive typing information to any cloud servers.

আমরা ব্যবহারকারীর তথ্যের গোপনীয়তাকে সর্বোচ্চ অগ্রাধিকার দিই। মুক্ত কিবোর্ড সম্পূর্ণ অফলাইন-ফার্স্ট এবং প্রাইভেসি-সুরক্ষিত নীতিতে তৈরি। আপনার টাইপ করা কোনো মেসেজ বা কি-স্ট্রোক আমরা কোনো দূরবর্তী সার্ভারে জমা বা ট্র্যাক করি না।

Amra user privacy ke shobcheye beshi priority dei. Mukto Keyboard fully Offline-First ebong Privacy-Centric system e toiri. Apnar type kora kono keystroke, message ba password amader ba onno kono server e kokhono jay na.

Zero Keylogging Guarantee

Zero Keylogging Guarantee
Strictly Protected: Mukto Keyboard does NOT log, store, or transmit your passwords, payment details, chat messages, or keystrokes to external servers. All typing stays strictly within the app you are typing in.
সম্পূর্ণ সুরক্ষিত: মুক্ত কিবোর্ড আপনার পাসওয়ার্ড, পেমেন্ট তথ্য, ব্যক্তিগত মেসেজ বা কোনো কি-স্ট্রোক কখনোই কোনো সার্ভারে পাঠায় না। আপনার লেখা কেবল আপনার নির্দিষ্ট অ্যাপের মধ্যেই থাকে।
Full Shurokkhito: Mukto Keyboard konodino apnar password, card details, personal chat ba keystrokes kono server e pathay na. Apni je app e type korchen, lekha shudhu shei app ei thake.

When enabling any custom keyboard, Android displays a default system warning stating that input methods can theoretically capture input text. This is a standard operating system warning for all third-party keyboards. Mukto Keyboard has no telemetry servers and collects zero keystroke logs.

অ্যান্ড্রয়েড ফোনে যেকোনো কিবোর্ড সক্রিয় করার সময় সিস্টেম থেকে একটি সাধারণ সতর্কবার্তা আসে যে কিবোর্ড আপনার লেখা দেখতে পারে। এটি গুগলের একটি স্বয়ংক্রিয় সতর্কবার্তা। মুক্ত কিবোর্ডে কোনো কি-লগিং ব্যবস্থা নেই।

Android phone e je kono keyboard enable korar shomoy system theke ekta warning show kore je keyboard text capture korte pare. Eta shob keyboard er jonno Android er default warning. Mukto Keyboard kono keylogger use kore na.

Voice Typing & Microphone Usage
ভয়েস টাইপিং ও মাইক্রোফোন ব্যবহার
Voice Typing o Microphone

The RECORD_AUDIO permission is used solely when you explicitly tap the microphone button to convert spoken speech to text using Android's platform speech service.

কিবোর্ডের মাইক্রোফোন আইকনে ট্যাপ করে কথা বলে টাইপ করার সুবিধার জন্য RECORD_AUDIO পারমিশন প্রয়োজন হয়।

Keyboard er mic button e tap kore mukhe bole type korar jonno RECORD_AUDIO permission use hoy.

No Audio Recording Storage: We do NOT save, store, or archive your voice recordings. The audio stream is converted into text in real-time and immediately discarded. There is no background listening.
কোনো অডিও সংরক্ষণ করা হয় না: আপনার কণ্ঠস্বর কোনো ফাইল আকারে সেভ বা সংরক্ষণ করা হয় না। কথা টেক্সটে রূপান্তরিত হওয়ার পরপরই অডিও মুছে যায়। ব্যাকগ্রাউন্ডে কোনো গোপন অডিও শোনা হয় না।
Audio Save Hoy Na: Apnar kotha shonar por real-time text e convert hoye audio shathe shathe delete hoye jay. Kono audio file save hoy na ebong background e kono listening chole na.

Clipboard History Protection
ক্লিপবোর্ড হিস্ট্রি ও নিরাপত্তা
Clipboard History & Security
  • Sensitive Clip Protection: Clips flagged as sensitive by Android 13+ or copied from password fields are ignored and never saved to clipboard history.
  • Local Storage Only: Clipboard clips reside strictly in local app memory and are never uploaded to any cloud.
  • Auto-Pruning: Unpinned clips automatically expire and are cleaned up. You can manually delete individual or all clips anytime.
  • Recent Screenshot 1-Tap Pasting: The keyboard clipboard automatically detects newly captured screenshots in the background via ContentObserver to show a convenient 1-tap paste suggestion chip in the keyboard toolbar. System photo pickers require manual user selection and cannot observe real-time background screenshot events. Only the single most recent screenshot is momentarily detected on-device; Mukto Keyboard never scans, indexes, stores, or transmits your photo gallery, albums, or camera media. All screenshot interaction is strictly on-device, temporary, and never uploaded to any server.
  • সংবেদনশীল ক্লিপ সুরক্ষা: অ্যান্ড্রয়েড ১৩+ এ সংবেদনশীল হিসেবে চিহ্নিত ক্লিপ বা পাসওয়ার্ড ফিল্ডের লেখা ক্লিপবোর্ডে সেভ হয় না।
  • লোকাল সংরক্ষণ: ক্লিপবোর্ডের সমস্ত ডেটা শুধু আপনার ফোনের মেমোরিতে থাকে, কোনো ক্লাউডে পাঠানো হয় না।
  • স্বয়ংক্রিয় প্রুনিং: আনপিন করা অপ্রয়োজনীয় ক্লিপ নির্দিষ্ট সময় পর নিজে থেকেই মুছে যায় এবং আপনি যেকোনো সময় যেকোনো ক্লিপ ডিলিট করতে পারেন।

App Crash Hole Ki Ki Information Collect Hoy?

  • Stack Traces: The exact code line and internal exception where an error or crash occurred.

Diagnostic data is strictly used for software maintenance, debugging, and preventing future app crashes.
