Mukto Keyboard (Android Package ID: com.mukto.keyboard), developed by Md Mobassher Ahmed Sourav and published by JS Organization, is an input method editor (IME) engineered specifically for the Bengali and Banglish writing experience. From its initial line of code, Mukto Keyboard was built upon a strict Zero-Knowledge, Local-First Architecture.

মুক্ত কিবোর্ড (অ্যান্ড্রয়েড প্যাকেজ আইডি: com.mukto.keyboard), যা ডেভেলপার মোঃ মোবাশ্বের আহমেদ সৌরভ কর্তৃক ডেভেলপকৃত এবং JS Organization দ্বারা পরিচালিত, বাংলা ও বাংলিশ টাইপিংয়ের জন্য একটি আধুনিক অ্যান্ড্রয়েড ইনপুট মেথড (কিবোর্ড)। মুক্ত কিবোর্ডের মূল ভিত্তি হলো জিরো-নলেজ ও লোকাল-ফার্স্ট আর্কিটেকচার।

Mukto Keyboard (Package ID: com.mukto.keyboard), jar developer Md Mobassher Ahmed Sourav ebong JS Organization er shathe porichalito, Bangla o Banglish typing er ekta modern Android keyboard. Mukto Keyboard shuru thekei Zero-Knowledge o Local-First Architecture mene toiri.

Unlike conventional cloud-tethered keyboards, Mukto Keyboard does not maintain any user database, central cloud telemetry platform, or remote tracking servers. We do not require accounts, logins, phone numbers, or email addresses to use the keyboard. Your keystrokes, personal thoughts, and conversations are your private property.

প্রচলিত ক্লাউড-নির্ভর কিবোর্ডগুলোর মতো মুক্ত কিবোর্ডের কোনো কেন্দ্রীয় ইউজার ডেটাবেজ, ট্র্যাকিং সার্ভার বা ক্লাউড কি-লগিং সিস্টেম নেই। এই কিবোর্ড ব্যবহারের জন্য কোনো অ্যাকাউন্ট খোলা, লগইন করা, ফোন নম্বর বা ইমেইল দেওয়ার কোনো প্রয়োজন নেই। আপনার লেখা প্রতিটি শব্দ ও বার্তা একান্তই আপনার নিজস্ব সম্পত্তি।

Onnano cloud-based keyboard er moto Mukto Keyboard er kono central database, tracking server ba key-logging infrastructure nei. Keyboard chalate kono account open, login ba mobile number lage na. Apnar type kora shob kisu shudhumatro apnar e thakbe.

Keystroke shurokkhar technical guarantee

We provide an unequivocal technical guarantee: Mukto Keyboard NEVER intercepts, records, logs, or transmits your keystrokes to any remote server or third party.

আমাদের নীতি অত্যন্ত সুস্পষ্ট: মুক্ত কিবোর্ড আপনার টাইপ করা কোনো অক্ষর, শব্দ বা বাক্য কখনোই কোনো সার্ভারে রেকর্ড, লগ বা স্থানান্তর করে না।

Amader policy ekdom clear: Mukto Keyboard apnar type kora kono keystroke, password ba text kono server e kkokhono record ba transfer kore na.

  • No Keystroke Telemetry: Every tap on the keyboard is rendered strictly in local memory and passed directly to the active Android application input field.
  • Sensitive Field Immunity: When typing in password, PIN, or payment fields, autocorrect and predictive learning are automatically suppressed by the keyboard engine.
  • Private Browsing Respect: When Android's Incognito or Private mode is detected, dictionary learning is completely disabled to ensure total anonymity.
  • নো কি-স্ট্রোক টেলিমেট্রি: আপনি যখন কোনো বাটনে চাপ দেন, তা শুধুমাত্র ফোনের লোকাল মেমোরিতে প্রসেস হয়ে সরাসরি অ্যাপ্লিকেশনের ইনপুট বক্সে চলে যায়।
  • সংবেদনশীল তথ্য সুরক্ষা: পাসওয়ার্ড, পিন কোড বা পেমেন্ট কার্ড টাইপ করার সময় স্বয়ংক্রিয়ভাবে প্রেডিকশন ও লার্নিং বন্ধ থাকে।
  • ইনকগনিটো মোড সম্মান: প্রাইভেট বা ইনকগনিটো ব্রাউজিং মোড শনাক্ত হলে কিবোর্ড কোনো নতুন শব্দ শেখে না।
  • No Keystroke Telemetry: Keyboard er protiti tap local memory te process hoye direct active app er input field e chole jay.
  • Sensitive Field Security: Password, PIN ba card number type korar shomoy auto-learning complete bondho thake.
  • Incognito Mode Respect: Browser e Incognito ba Private mode e type korle dictionary learning automatic disable thake.

Phone er private sandbox e safe storage

Mukto Keyboard adapts to your unique writing style by remembering frequently typed words and personalized shortcuts. This learning mechanism operates entirely on-device:

আপনার নিজস্ব টাইপিং স্টাইল দ্রুত ও মসৃণ করতে মুক্ত কিবোর্ড ঘনঘন ব্যবহৃত শব্দ মনে রাখে। এই প্রেডিকশন ব্যবস্থা সম্পূর্ণভাবে আপনার ডিভাইসের ভেতরেই কাজ করে:

Apnar typing style shundor ebong fast korte Mukto Keyboard shobcheye beshi use kora shobdo mone rakhe. Ei system 100% on-device kaj kore:

  • Atomic Binary File (user_learning.bin): Learned vocabulary is structured in a high-speed in-memory Prefix Trie and saved atomically in the app's sandboxed private storage (context.filesDir). No other Android app can inspect or read this file.
  • Zero SQLite Overhead: Because dictionary learning uses an atomic binary serialization pattern rather than insecure shared databases, zero personal text is exposed across process boundaries.
  • Preferences in Android SharedPreferences: Visual theme choices, haptic feedback sliders, and layout selections are saved locally inside private application preferences.
  • অ্যাটমিক বাইনারি ফাইল (user_learning.bin): শেখা শব্দগুলো হাই-স্পিড ইন-মেমোরি প্রিফিক্স ট্রাই স্ট্রাকচারে সাজানো থাকে এবং অ্যাপের প্রাইভেট ডিরেক্টরিতে বাইনারি ফরম্যাটে সংরক্ষিত হয়। অন্য কোনো অ্যাপ এই ডেটা পড়তে পারে না।
  • কোনো ক্লাউড বা শেয়ার্ড ডাটাবেজ নেই: সমস্ত শব্দ আপনার ডিভাইসের ইন্টারনাল ফাইলে এনক্রিপ্টেড স্যান্ডবক্সে থাকে, ফলে কোনো তৃতীয় পক্ষ এতে ঢুকতে পারে না।
  • লোকাল সেটিংস: থিম নির্বাচন, ভাইব্রেশনের মাত্রা বা লেআউট পরিবর্তন সবকিছু অ্যান্ড্রয়েডের নিজস্ব প্রাইভেট শেয়ার্ড প্রেফারেন্সে সেভ থাকে।
  • Atomic Binary File (user_learning.bin): Learnt shobdo gulo high-speed Prefix Trie structure e app er private folder e binary akare save thake. Onno kono app eta porte pare na.
  • No Cloud ba Shared DB: Shob kichu internal storage er secure sandbox e thake, kono external database nei.
  • Local Settings: Theme, vibration intensity, layout preferences shob Android er private shared preferences e thake.

Mukto Keyboard features a state-of-the-art Camera OCR Scanner that allows you to scan text from books, physical documents, receipts, or gallery photos directly into your keyboard input field. Privacy and security during OCR are strictly enforced:

মুক্ত কিবোর্ডে রয়েছে অত্যাধুনিক ক্যামেরা ওসিআর স্ক্যানার, যার মাধ্যমে বই, খাতা, সাইনবোর্ড বা গ্যালারির যেকোনো ছবি থেকে সরাসরি কিবোর্ডে টেক্সট স্ক্যান করা যায়। এই ফিচারের প্রাইভেসি আর্কিটেকচার অত্যন্ত সুরক্ষিত:

Mukto Keyboard e ache modern Camera OCR Scanner, jar maddhome boi, paper ba gallery photo theke direct keyboard e text scan kora jay. Tar privacy niye amader strict rules ache:

  • 100% On-Device Recognition: Powered by Google ML Kit Text Recognition (Latin & Bengali OCR) running entirely inside local device memory using Android CameraX.
  • Zero Image Storage or Upload: Camera preview frames and picked images are processed in volatile memory (RAM) only. Mukto Keyboard NEVER uploads, saves, copies, or transmits your photos to any cloud server.
  • Instant Memory Disposal: As soon as the detected text lines are transferred to your keyboard input box, the image buffers and temporary bitmap references are immediately purged from memory.
  • শতভাগ অন-ডিভাইস স্ক্যানিং: গুগল এমএল কিট টেক্সট রিকগনিশন (ML Kit Text Recognition) এবং অ্যান্ড্রয়েড ক্যামেরাক্স (CameraX) দিয়ে স্ক্যানিং সম্পূর্ণ আপনার ফোনের প্রসেসর ও র‍্যামে (RAM) সম্পন্ন হয়।
  • কোনো ছবি আপলোড বা সংরক্ষণ নেই: ক্যামেরার লাইভ ফ্রেম বা নির্বাচিত ফটো কখনোই কোনো সার্ভার, ক্লাউড বা ইন্টারনেটে পাঠানো হয় না। মুক্ত কিবোর্ড কোনো ছবি তার স্টোরেজে সেভ করে রাখে না।
  • তাৎক্ষণিক মেমোরি নিষ্কাশন: স্ক্যান করা লেখা কিবোর্ডের টেক্সট বক্সে পেস্ট হওয়ার সাথে সাথেই মেমোরি থেকে ছবির সমস্ত তথ্য স্থায়ীভাবে ডিলিট হয়ে যায়।
  • 100% On-Device Recognition: Google ML Kit Text Recognition o CameraX diye pura scanning phone er RAM e hoy, internet connection er dorkar hoy na.
  • Zero Image Storage ba Upload: Mukto Keyboard apnar kono photo, video ba camera frame kono server e pathay na ebong nijer storage eo save kore na.

Understanding the Android System Dialog অ্যান্ড্রয়েড সিস্টেম সতর্কবার্তা সম্পর্কে জানুন Android System Warning Ki?

When you enable any third-party keyboard on Android, the operating system displays a mandatory standard dialog: "This input method may be able to collect all the text you type, including personal data like passwords and credit card numbers."

অ্যান্ড্রয়েডে যেকোনো থার্ড-পার্টি কিবোর্ড অন করার সময় অপারেটিং সিস্টেম একটি সতর্কবার্তা প্রদর্শন করে: "This input method may be able to collect all the text you type, including passwords and credit card numbers..."

Android e jekono notun keyboard on korar shomoy system standard warning dekhay: "This input method may be able to collect all the text you type..."

This is a generic warning displayed by Android for ALL third-party keyboards without exception. Mukto Keyboard does NOT log or transmit your personal data. Our architecture guarantees that your keystrokes never leave your phone.

এটি অ্যান্ড্রয়েড অপারেটিং সিস্টেমের একটি জেনেরিক সতর্কবার্তা যা বিশ্বের সকল থার্ড-পার্টি কিবোর্ডের ক্ষেত্রেই প্রদর্শিত হয়। মুক্ত কিবোর্ড কোনো কি-লগিং করে না এবং আপনার টাইপ করা কোনো তথ্য কখনোই আপনার ফোন থেকে কোথাও স্থানান্তরিত হয় না।

Eta Android OS er generic warning ja shob keyboard er jonnoi ashe. Mukto Keyboard kono keystroke capture kore na ebong apnar data shudhu apnar phone ei thake.

Declared App Permissions: ব্যবহৃত পারমিশনসমূহের বিবরণ: Permissions Details:

  • BIND_INPUT_METHOD: Required core permission for Android to recognize and run Mukto as an Input Method Editor.
  • RECORD_AUDIO: Used exclusively for speech-to-text voice typing when you tap the microphone button.
  • CAMERA: Optional permission for the Camera OCR Text Scanner to extract text lines from physical papers or books. Operates 100% on-device.
  • READ_MEDIA_IMAGES (Android 13+) / READ_EXTERNAL_STORAGE (Android 12 & below): Used only when you choose a custom photo/video for your keyboard theme, pick an image to OCR scan, or explicitly turn on recent screenshot suggestions.
  • VIBRATE: Used solely to provide tactile haptic feedback during keypresses.
  • INTERNET & ACCESS_NETWORK_STATE: Used for on-demand capabilities: downloading ML Kit offline translation packages, executing direct AI API calls (BYOK), syncing Google Drive backups, and sending anonymous Crashlytics crash traces.
  • BIND_INPUT_METHOD: অ্যান্ড্রয়েড অপারেটিং সিস্টেমে কিবোর্ড হিসেবে কাজ করার জন্য প্রয়োজনীয় বাধ্যতামূলক পারমিশন।
  • RECORD_AUDIO: শুধুমাত্র আপনি যখন মাইক্রোফোন বাটনে চাপ দিয়ে মুখে বলে টাইপ করেন, কেবল তখনই ভয়েস টাইপিংয়ের জন্য ব্যবহৃত হয়।
  • CAMERA: ক্যামেরা ওসিআর স্ক্যানার ব্যবহার করে বই বা কাগজ থেকে সরাসরি টেক্সট স্ক্যান করার জন্য প্রয়োজন হয়। শতভাগ অন-ডিভাইসে চলে।
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE: কিবোর্ডের ব্যাকগ্রাউন্ডে নিজের ছবি বা ভিডিও থিম সেট করা, স্ক্যান করার জন্য ছবি নির্বাচন করা এবং অপশনাল স্ক্রিনশট পেস্ট চিপের জন্য ব্যবহৃত হয়।
  • VIBRATE: বাটনে চাপ দেওয়ার পর আঙুলে হ্যাপটিক ভাইব্রেশন ফিডব্যাক দেওয়ার জন্য।
  • INTERNET & ACCESS_NETWORK_STATE: অফলাইন অনুবাদের ভাষা প্যাক ডাউনলোড, এআই রিকোয়েস্ট (BYOK), গুগল ড্রাইভ ব্যাকআপ এবং ক্র্যাশলিটিক্সে এরর রিপোর্ট পাঠানোর জন্য।
  • BIND_INPUT_METHOD: Android e keyboard hishabe kaj korar standard permission.
  • RECORD_AUDIO: Voice typing mic button tap korle speech-to-text er jonno use hoy.
  • CAMERA: Camera OCR text scanner e boi ba kagoj theke text scan korar jonno use hoy (100% on-device).
  • READ_MEDIA_IMAGES / READ_EXTERNAL_STORAGE: Keyboard theme e custom photo/video set kora ba photo theke OCR korar jonno.
  • VIBRATE: Keypress e tactile haptic vibration er jonno.
  • INTERNET & ACCESS_NETWORK_STATE: Translation pack download, user er direct AI API call, Google Drive sync ebong crash report er jonno.

Jehetu shob data apnar phone ei thake, tai jekono shomoy data delete ba clear korar full power apnar:

  • Clear Learned Words: Open Mukto Keyboard Settings > Dictionary > Tap "Clear Learned Words" to instantly wipe user_learning.bin from storage.
  • Wipe Clipboard History: Open the clipboard panel and tap the trash icon to erase all clips immediately.
  • Remove AI Keys: Open AI Settings and clear your API keys anytime. They are permanently removed from private SharedPreferences.
  • Delete Cloud Backups: Delete your backup file from Google Drive AppData via settings, or remove the local .mukto file from your storage.
  • Complete Uninstallation: Uninstalling Mukto Keyboard from your Android device causes the operating system to permanently delete all local sandbox files and cached preferences.
  • শেখা শব্দ মুছে ফেলা: সেটিংসের ডিকশনারি অপশনে গিয়ে "Clear Learned Words" চাপলেই সমস্ত শেখা শব্দ মেমোরি থেকে চিরতরে ডিলিট হয়ে যাবে।
  • ক্লিপবোর্ড মুছে ফেলা: ক্লিপবোর্ড প্যানেলে থাকা ট্র্যাশ আইকনে চাপ দিলে সব সংরক্ষিত ক্লিপ এক ক্লিকেই মুছে যায়।
  • এআই কি ডিলিট: এআই সেটিংস থেকে যেকোনো সময় আপনার এপিআই কি মুছে ফেলতে পারেন।
  • ব্যাকআপ ডিলিট: গুগল ড্রাইভের ব্যাকআপ সেটিংস থেকে মুছে ফেলা যায় অথবা ফোনের মেমোরি থেকে .mukto ফাইলটি ডিলিট করতে পারেন।
  • অ্যাপ আনইনস্টল: ফোন থেকে মুক্ত কিবোর্ড আনইনস্টল করার সাথে সাথে সমস্ত লোকাল ফাইল স্বয়ংক্রিয়ভাবে মুছে যায়।
